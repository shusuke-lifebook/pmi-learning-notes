# pmi-learning-notes

PMI（Project Management Institute）の標準類、PMP学習内容、  
およびプロジェクトマネジメントに関する知識を体系的に整理するためのリポジトリ。

修介の学習ログ、図解、要点整理、実務への適用メモを蓄積し、  
PM体系化・部下育成・技術領域の整理に活用する。

---

## 📚 Purpose（目的）

- PMBOK® Guide（第7版）および PMI Standards の理解と体系化  
- PMP試験対策（ECO、ハンドブック、出題領域の整理）  
- Agile / Hybrid / Scrum の実務適用ノート  
- 組織改善・リーダーシップ・ステークホルダー管理の知識整理  
- 部下育成のための教材化（図解・要点まとめ）  
- プロジェクトマネジメントに関する継続的な学習ログの蓄積

---

## 📁 Repository Structure（構成）

```
pmi-learning-notes
├── pmbok/                 # PMBOK第7版の要点・図解・まとめ
├── agile/                 # Agile Practice Guide / Scrum / Hybrid
├── standards/             # PMI標準類（WBS, Risk, Schedulingなど）
├── pmp/                   # PMP試験対策（ECO、ハンドブック要点）
├── notes/                 # 日々の学習ログ・気づき・実務適用メモ
├── diagrams/              # 図解（draw.io / Mermaid / PNGなど）
└── resources/             # 参考資料・外部リンク・引用元
```

## 📝 Contribution Rules（運用ルール）

- Markdown形式で記録する  
- 1トピック1ファイルを基本とする  
- 図解は `/diagrams` にまとめる  
- 実務で得た知見は `/notes` に随時追加  
- PMP対策は `/pmp` に集約し、ECOに沿って整理する  
- PMI標準類は `/standards` に分類して体系化する
